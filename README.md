## 🌟 Proyecto destacado: Steam Games Pipeline

Pipeline de datos completo end-to-end sobre **67.000 juegos de Steam** y un dominio simulado de partidas multijugador con más de **400.000 registros**.

**Arquitectura medallion:** Bronze → Silver → Gold en Snowflake, transformaciones con dbt Cloud y visualización en Power BI con tema personalizado.

**Características técnicas:**
- 🥉 Bronze: ingesta cruda de 4 tablas
- 🥈 Silver: limpieza y normalización en 13 tablas según ERD
- 🥇 Gold: dos data marts en esquema estrella con dimensiones conformadas
- ⚙️ Modelos incrementales sobre tablas de 400.000+ filas
- 📸 Snapshot SCD-2 para histórico de cambios
- ✅ Testing en tres niveles (genérico, custom y singular)
- 🔄 Orquestación con jobs en dbt Cloud (deps → seed → run → test → snapshot)
